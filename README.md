# 🍹 Cocktail Recipe Finder

A web application built using Express.js, Axios, and EJS. It fetches random cocktail recipes from TheCocktailDB API and displays the recipe information in a user-friendly webpage.

## Features

- Fetches a random cocktail using Axios.
- Displays the cocktail name and image.
- Shows ingredients and measurements.
- Displays preparation instructions.
- Includes error handling for API requests.
- Uses EJS for dynamic HTML rendering.

## Technologies Used

- Node.js
- Express.js
- Axios
- EJS
- HTML and CSS
- TheCocktailDB API

## How to Run

1. Clone the project or download the files.
2. Open the project folder in Terminal.
3. Install dependencies:

   bash:
   npm install
    

4. Start the server:

   bash:
   npm run dev
   

5. Open this URL in your browser:

   http://localhost:3000

## API Endpoint

GET https://www.thecocktaildb.com/api/json/v1/1/random.php
